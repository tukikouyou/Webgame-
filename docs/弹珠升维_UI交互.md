# 《弹珠升维》正式版 UI 与交互方案 v0.1

> 正式版用 Godot 4 + C#。玩法规则以网页 demo 为准(见 `弹珠升维_demo说明.md`),本文只定界面和操作。
> 已确定(韩丰):长条 = 钉板切段 + 战场 + HUD;展开 = 单独弹出窗口;窗口内用页签;提醒 = 长条上的发光图标。

---

## 一、两个窗口

| 窗口 | 形态 | 作用 |
|---|---|---|
| **长条** | 屏幕底部,全屏宽、约 130px 高;无边框、背景透明、置顶;只有内容区域接收鼠标,其余地方点击穿透到下面的软件 | 挂机看进度;点图标打开管理窗口 |
| **管理窗口** | 普通窗口,可拖动、可缩放、记住位置和大小;关掉后长条照常运行 | 所有管理操作:升级、摆钉子、排槽位、抽卡、传承、设置 |

- 游戏一直在长条里运行;管理窗口只是「操作面板」,开着关着都不影响推进。
- **右键长条**弹出小菜单:打开管理窗口 / 暂停 / 退出游戏。
- 长条放在哪块显示器、贴底还是贴顶,在「设置」里选(默认主显示器底部)。

## 二、长条布局(以 1920 宽为例)

```
┌──────┬──────┬──────┐┌──────────────────────────────────────────┐┌──────────┐
│ ·  · │ ·  · │ ·  · ││▓▓▓▓▓▓▓▓▓▓▓▓│▒▒▒▒▒▒▒▒▒▒  ←● ●        ║BOSS║││ 5 维·第2区│
│  ·  ·│  ·  ·│  ·  ·││   🔫 ●●●→  │ 前线        ▒▒▒▒▒▒▒▒▒▒  ║    ║││ 金 1.2B/s │
│ ·  · │ ·  · │×发×+×││▓▓▓▓▓▓▓▓▓▓▓▓│▒▒▒▒▒▒▒▒▒▒             ║    ║││ 弹 ▓▓▓░ 3.8M│
└──↓───┴──↓───┴──────┘└──────────────────────────────────────────┘│ ⟳ 🎴 ★ ⌛ ✦ │
  钉板(3 段并排)                   战场(横向卷轴)                   └──────────┘
     约 570px                            约 1130px                       约 220px
```

### 钉板(左)
- 竖向钉板切成 **3 段并排**。球落到一段的底部后,经过管道动画从下一段顶部继续落;最后一段的底部是落槽。
- 正式版里钉板的几何本身就按「3 段」设计:**管理窗口里按原始大小显示,3 段合并成一整块完整竖板**;长条里是 3 段并排(按长条高度缩放)。同一套数据两种摆法,逻辑不关心怎么摆。
- 落槽格按功能上色(倍增 / 发射 / 空槽 / 卡牌槽);球落槽时对应格闪一下。

### 战场(中)
- 横向卷轴,13 行(每格约 10px),镜头跟随前线。
- boss 关时,战场顶部叠一条细的 boss 血条(破盾前显示占领进度,破盾后显示血量)。
- 升维时战场闪白 + 中间飘字「升维 → N 维」。

### HUD(右)
从上到下:
1. **位置**:「5 维 · 第 2 区」/「5 维 · BOSS」
2. **金币**:当前金币 + 每秒收入
3. **弹药条**:蓄力弹药 / 发射上限(满了自动发射)
4. **状态图标行**(有事可做时发光,点击直接打开管理窗口的对应页签):

| 图标 | 发光条件 | 点击打开 |
|---|---|---|
| ⟳ 转生 | 本轮最远纪录一段时间没刷新(撞墙) | 管理窗口(顶栏有转生按钮) |
| 🎴 卡包 | 星砂够开一包 | 卡牌页 |
| ★ 三选一 | 有待选的卡 | 卡牌页 + 三选一弹窗 |
| ⌛ 纪元 | 本轮已到 5 维,可以终结纪元 | 卡牌页(终结纪元按钮) |
| ✦ 传承 | 本轮已到 10 维,可以传承 | 传承页 |

- 鼠标悬停 HUD 显示详细数字(能量、星砂、传承点、转生可得多少能量等)。
- 不弹窗、不出声,只靠发光提醒。

## 三、管理窗口

### 顶栏(所有页签共用)
```
┌────────────────────────────────────────────────────────────────┐
│ 金币 1.2B │ 能量 340 │ 星砂 85 │ 传承点 2 │  [转生 +12 能量]  [⌛终结纪元 +28]  │
├──────┬──────┬──────┬──────┬──────┬───────────────────────────────┤
│ 炮台 │ 钉板 │ 卡牌 │ 传承 │ 设置 │                               │
└──────┴──────┴──────┴──────┴──────┴───────────────────────────────┘
```
- 转生是最常用的操作,常驻顶栏;终结纪元 / 传承在可用时才出现在顶栏。

### 通用交互
| 操作 | 效果 |
|---|---|
| 左键点升级按钮 | 升 1 级 |
| **Ctrl + 点击** | 升 5 级(钱不够就升到买得起的最大级数) |
| **Shift + 点击** | 升 10 级(同上) |
| **长按** | 连续升级,越按越快 |
| **右键** | 切换开关类设置(例如「自动升级跳过这一项」),按钮上显示小图标表示状态 |
| 悬停 | 显示说明和下一级效果 |
| 终结纪元 / 传承 / 重置存档 | 窗口内确认对话框(不用系统弹窗) |

### 页签:炮台
- 升级列表:伤害 / 发射上限 / 底弹(以后加更多)。每行:名称、等级、当前 → 下一级、价格。
- 「自动升级」总开关在列表顶部;单项的「自动跳过」用右键切换。

### 页签:钉板
```
┌───────────── 钉板(3 段竖着拼成完整竖板)──────────┐┌──────────────┐
│   ·   ·   ·   ·   ·   ·   ·                      ││ 钉子仓库      │
│ ·   ·   ◆   ·   ·   ·   ·   ·                    ││ ◆暴击 ◆本体   │
│   ·   ·   ·   ·   ◆   ·   ·                      ││ ◆分裂 ◆金币   │
│ ── 段 1 / 段 2 分界(管道)──                     ││ ◆炸弹         │
│   …                                              ││──────────────│
├──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┤                ││ 选中:◆本体 Lv3│
│× │  │发│  │× │  │  │发│  │× │  │  │  ← 落槽        ││ [升级 6.8能量]│
└──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┘                ││ [移除]        │
                                                      └──────────────┘
```
- **摆钉子**:先在右侧选一种钉子(或点「买新钉子」),再点钉板上任意一颗普通钉,把它换成特殊钉。点已摆好的特殊钉 → 右侧显示升级 / 移除;拖动可以换位置。
- **排落槽**:点底部任意一格,弹出小菜单选「倍增 / 发射 / 空 / 卡牌给的槽」。已解锁的功能格数量有上限,超出时菜单里相应选项变灰。
- 顶部显示「已解锁功能格 n / 12」和「再解锁 1 格」按钮。
- 钉板实时运转(球照常在弹),改动立刻生效。

### 页签:卡牌
- 上半:卡包区(不同卡包的价格、出率说明、「开包」按钮)。
- 下半:已拥有的卡(网格,显示层数),未解锁的灰显。
- **三选一**:开包后在窗口中央弹出 3 张卡,点一张拿走;不选可以先关掉,之后从长条的 ★ 图标回来继续选。
- 终结纪元按钮也放在这一页(显示本轮可得星砂和计算方式)。

### 页签:传承
- 天赋列表(名称、说明、价格、已拥有状态);「进行传承」按钮(显示可得传承点)。

### 页签:设置
- 数字单位:英文(K/M/B/T/aa…)/ 字母(K/M/A/B/C…)/ 科学计数法
- 长条:显示器、贴底 / 贴顶、透明度
- 自动转生的秒数
- 存档:导出 / 导入 / 重置(重置需要确认)

### 开发者面板
- 只在开发版里,按 F12 打开:倍速、加资源、实时改数值参数(沿用 demo 调试页)。
