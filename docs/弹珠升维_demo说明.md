# 《弹珠升维》核心玩法 demo 说明

网页版 demo,只用来验证核心循环和数值;正式版计划用 Godot 4 + C#,逻辑层(`src/idle/core/`)照着翻译。
原游戏(`index.html`、`src/` 其余部分)没有改动。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/idle.html`。进度每 5 秒自动存到浏览器 localStorage,调试页可以重置。

## 四层循环

| 层 | 做什么 | 货币 | 花在哪 | 下一层的入口 |
|---|---|---|---|---|
| 推进 | 炮台齐射打格子、推前线 | 金币 | 炮台升级(伤害 / 发射上限 / 底弹) | 推不动了 → **转生** |
| 转生 | 从 1 维 1 区重推 | 维度能量 | 钉子(买 / 升级)、解锁功能槽宽 | **当前这一轮**推到 **5 维** → 可终结纪元;星砂按小关(区)累加:本轮推过的第 i 个区得 0.5 × 1.11^(i−1)(约每维 ×1.5;5-1 得 19,5-2 得 22,5-3 得 25,5-BOSS 得 28,6-1 得 32,8-1 得 79,10-1 得 190) |
| 纪元 | 开卡包三选一 | 星砂 | 6 张数值卡 | **当前这一轮**推到 **10 维** → 可传承;传承点 = 1 + (本轮维度 − 10) |
| 传承 | 永久成长 | 传承点 | 解锁卡池、天赋 | — |

- 每维 = 3 个普通区 + 1 个 boss 区(白板 boss),每区 40 列,战场连续延伸。
- boss 站在 boss 区最右端的墙上,区内每一格都打得到。普通 boss:弹珠飞到末端墙(任意一行)就算命中(破盾前被护盾挡下);圆形碰撞(只有 boss 上下 ±24 像素内才算)留作以后特殊 boss 的特性,调试页可以切换体验。boss 区敌格降到 10% 以下护盾破除(破盾后隐藏占领条),击毁 boss → 升维,本轮继续推。boss 每秒回复 1% 最大血量,破盾后的回血相当于第二阶段。
- **6 维起 boss 全程满火力**:不再按区递增,从这一维开局就每秒 7 颗(和 boss 区一样)。
- **6 维起取消巩固区**:只有上一维以前的格子是稳固的,当前这一维从第 1 区到 boss 区都可以被 boss 抢回,我方和 boss 在整个维度里拉锯(5 维以前巩固区照旧在前线后方 20 列)。敌方弹珠依旧飞到哪个区就按哪个区的格子血量结算。
- **6 维起 boss 有自己的钉板**(画在右上角):2 颗球、3 格倍增、2 格发射,每颗球落槽 +1 弹药,落进发射槽或蓄满 40 就齐射一波敌方弹珠,叠加在常规火力之上(起始维度、球数、齐射上限可在调试页调)。
- **敌方弹珠全部由 boss 发射**,每一维开局就开火:前线在第 1 区时每秒 1 颗,每推进一个普通区多 1.5 颗(1-2 是 2.5 颗、1-3 是 4 颗),前线进入 boss 区后每秒 7 颗。敌方弹珠的威力按「飞进的那个区的格子满血」换算;穿过被打残的敌格时先把它补满,碰到我方格子则抢回。
- 钉子 5 种颜色只是种类标记,demo 里效果相同:被球撞到时弹药 + 数值。
- 落槽:每颗球落进任何槽都先 + 底弹,再结算槽效果——空槽只有底弹;倍增 ×(1 + m × 0.7^(k−1));发射把 min(弹药, 发射上限) 打出去,超出的部分留到下一轮(最多等于上限)。所以解锁功能格永远是增强。
- **蓄力弹药达到发射上限时自动发射**;发射上限用金币升级(上限越高,单次齐射越大,倍增也能在更大的弹药池上滚雪球)。
- 弹药多时弹珠自动合并成大弹珠(场上最多 400 颗)。
- 没有碾压模式:推得快慢完全由格子血量决定,血量低时大弹珠会一路穿透过去。打过 boss 会清空场上弹珠。
- 格子血量按「全局第几区」连续增长(每区 ×4):1-3 = 16,1 维 boss 区 = 320(boss 倍率 ×5),2-1 = 64,2-2 = 256……能量价值同样连续增长(每区 ×1.6)。
- 到达 2 维后解锁自动升级、自动转生;炮台页每项升级右边有开关,可以让自动升级跳过该项。

## 当前默认数值(`src/idle/config/tuning.ts`)

边跑模拟边调过一轮,和设计稿初值不同的地方:

| 参数 | 值 | 为什么 |
|---|---|---|
| 伤害每级 / 价格每级 | ×1.09 / ×1.15 | 只靠金币时火力要落后于敌方成长,才会撞墙 |
| 底弹 初始 / 每级 / 价格每级 | 10 / ×1.1 / ×1.6 | 原来的底弹收益增长比价格快,导致数值失控 |
| boss 本体血量 | boss 区格子总血量 × 2,每秒回 1% | 破盾后进入第二阶段:每维第一次打到 boss 时大约 30~130 秒打死,基本不会卡到需要转生(原来破盾后 1~15 秒就死) |
| 发射上限 每级 / 起步价 / 价格每级 | ×1.55 / 5 / ×4.5 | 金币每维 ×256,上限价格倍率要远大于效果倍率,上限才会每维约 ×5、和实际齐射保持同一量级(原来 10 维上限 1.9e26、齐射才 5 亿) |
| boss 区格子倍率、boss 区发射 | ×5、7 颗/秒 | 让第一次到 boss 通常打不过 |
| boss 在普通区的发射 | 1 颗/秒起,每区 +1.5 | 开局不被压住,越往后压力越大,平滑涨到 boss 区的 7 颗 |
| 钉子基础弹药 | 25 | 转生后钉子的提升要明显 |
| 区域能量基数 | 4 | 每轮转生的能量足够买到看得见的提升 |
| 功能槽位置 | 整排均匀分布 | 放在中间时球很少落进空槽,开局弹药太少 |

模拟玩家(自动升级、推不动 60 秒就转生、能量买最便宜的项目、连续两轮没刷新本纪元最高维度、并且当前这一轮在 5 维以上时才终结纪元)的节奏:

- 第 1 轮约 3~5 分钟卡在 1 维第 2~3 区;之后每轮转生大约多推一维,一轮 5~10 分钟;
- 第 1 个纪元约 47 分钟到达 5 维;
- 第 2 个纪元约 2 小时推到 10 维,完成第一次传承。

## 调试页

- 倍速 ×1 ~ ×30(页面顶部也有)。
- 直接加金币 / 能量 / 星砂 / 传承点,重置存档。
- 20 多个关键参数可以实时修改,改完立即生效(刷新页面会恢复默认值)。

## 代码结构

```
idle.html
src/idle/
  config/tuning.ts   全部数值参数
  core/              纯逻辑,不碰 DOM/Canvas
    grid.ts          列号 → 维度/区号、格子血量、区域能量价值
    field.ts         列的生成与巩固、前线、boss、金币收入
    marbles.ts       我方齐射与合并、弹珠物理、敌方弹珠(boss 发射)
    plinko.ts        钉板落球、特殊钉、落槽效果、发射
    economy.ts       价格与购买
    prestige.ts      转生 / 终结纪元 / 传承、天赋
    cards.ts         卡池、开包三选一
    state.ts step.ts types.ts fx.ts format.ts
  render/renderer.ts Canvas 渲染
  ui/panel.ts        下方操作面板与卡牌弹窗
  ui/save.ts         localStorage 存档
  main.ts            入口与主循环
```
